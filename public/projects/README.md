# Project Screenshots

Drop your project screenshots here with these exact filenames:

- `staynest.png`    → StayNest screenshot
- `snapgallery.png` → SnapGallery screenshot
- `chatbot.png`     → AI Chatbot screenshot

Recommended size: 1200×900px (4:3 ratio) or similar widescreen crop.
The images will appear in the Projects section and clicking them opens the live demo.
